# MBAL Gas-Condensate Project

Проект переносит расчётную логику промысловой Excel-модели в Python.

Реализованы листы PVT, КГФ, P/Z, «Состав», ГДИ, «Продуктивность»,
«Температура», «База», «Период. раб.», «ГРП» и «Сводный отчёт». Входы и
результаты каждого модуля находятся рядом с контроллером в `code_sheets/`.

Листы исходной книги ВНС, прочих ГТМ, ЗБС, ПВЛГ, РС и ВБД пока не
перенесены полностью. Их рассчитанную добычу можно передать в
`Base.table_data` через колонки `Qgas_*` и `Qcond_*`; при отсутствии колонок
их вклад равен нулю.

## Структура

`code_sheets/` — контроллеры по листам:

- PVT — свойства газа (Z, плотность, вязкость, Bg)
- KGF — конденсатогазовый фактор
- PZ — материальный баланс
- Productivity — продуктивность скважин
- GDI — гидродинамическая интерпретация
- Temperature — устьевая температура и давление
- Components — изменение состава газа
- Base — сводный расчёт фонда и добычи
- Periodic — периодический фонд, движение скважин и его добыча
- GRP — когортный расчёт прироста добычи после ГРП
- Summary — помесячный и годовой сводный отчёт с вкладами ГТМ

`code_MBAL/` — библиотека расчётных функций.

`runner.py` — последовательный запуск полного расчёта.

## Установка и запуск

```powershell
py -3.10 -m pip install -r requirements.txt
py -3.10 runner.py
```

Запуск отдельного модуля выполняется из корня проекта, например:

```powershell
py -3.10 code_sheets/PVT/pvt_controller.py
```

При сборке в `.exe` все контроллеры читают входы и записывают результаты в
`run_data`. Изменённые пользователем файлы там сохраняются и не
перезаписываются исходными данными при следующем запуске. При запуске из
исходников тем же рабочим каталогом служит корень проекта.

## Результаты и ограничения

«База» строит условный прогноз на 1200 месяцев (100 лет). По умолчанию
применяются ограничения исходной книги: максимальная депрессия 10 МПа,
минимальная скорость на забое 1,5 м/с, максимальная скорость на устье 26 м/с
и минимальное устьевое давление 5 МПа. Причина остановки записывается в
`operation_limit`. Автоматический повторный запуск после остановки выключен;
при необходимости его можно включить параметром `restart_stopped_wells`.

Помесячные ввод и выбытие базовых скважин можно задать в `Base.table_data`
колонками `vvod_wells_in_curr_period`, `leave_base_fond` и
`time_prod_leaving_wells`. Сводный отчёт сохраняется в
`code_sheets/Summary/summary_output.json`.

## Периодическая эксплуатация и ГРП

Оба расчёта выполняются внутри помесячного цикла «Базы»: они получают
пластовое давление на начало месяца, их газ входит в общую добычу, после чего
материальный баланс определяет давление конца месяца. Поэтому вклад не
запаздывает на один период.

В `code_sheets/Periodic/periodic_input.json` и
`code_sheets/GRP/grp_input.json` доступны два режима:

- `external` сохраняет переданные в `Base.table_data` готовые значения;
- `calculated` рассчитывает вклад по графику и запрещает одновременно задавать
  готовые значения тех же `Qgas_*`/`Qcond_*`, чтобы не было двойного учёта.

Для периодического фонда перевод задаётся только полем
`wells_transferred_from_base` его графика. В том же месяце число скважин
вычитается из базового фонда и добавляется в периодический. ГРП считается по
когортам: параметры `before`/`after` фиксируются в месяц события, а прирост
дебита каждой когорты пересчитывается при текущем давлении до конца горизонта.
Как и в исходной книге, `well_count` ГРП означает число обработок для расчёта
прироста: оно не перемещает скважины между фондами и не отключается
автоматически при остановке базовой добычи. Согласованность программы ГРП с
реальным фондом остаётся ответственностью сценария.
Для детального аудита вклада каждой когорты можно включить
`include_cohort_details`; по умолчанию он выключен, чтобы 100-летний JSON не
разрастался квадратично.

`Periodic.strict_excel_compatibility=true` воспроизводит технические
особенности исходных формул (20 °C в `Pust` и пластовую температуру для
скорости на устье). Значение `false` использует физически согласованные
температуры и MD/TVD скважины.

В сводном отчёте помесячные поля `mean_*` повторяют формулы Excel. Поля
`operating_*` дополнительно показывают физические показатели по фактически
работающим скважино-суткам и не усредняют давление с отсутствующим фондом.
Годовые давления усредняются по всем месяцам года; это намеренно исправляет
ошибку `База!Q98` исходной книги, где для 2024 года взяты только июль–декабрь.

Контроллеры сохраняют расчётные JSON-файлы и PNG-графики в своих папках.

```powershell
py -3.10 -m unittest discover -s tests -v
```
