# MBAL Gas-Condensate Project

Проект переносит расчётную логику промысловой Excel-модели в Python.

Реализованы листы PVT, КГФ, P/Z, «Состав», ГДИ, «Продуктивность»,
«Температура» и «База». Входы и результаты каждого модуля находятся рядом
с контроллером в `code_sheets/`.

Листы исходной книги ВНС, ГРП, прочих ГТМ, ЗБС, ПВЛГ, РС и ВБД пока не
перенесены отдельными контроллерами. Их рассчитанную добычу можно передать в
`Base.table_data` через колонки `Qgas_*` и `Qcond_*`; при отсутствии колонок
их вклад равен нулю.

## Структура

`code_sheets/` — контроллеры по листам:

- PVT — свойства газа (Z, плотность, вязкость, Bg)
- KGF — конденсатогазовый фактор
- PZ — материальный баланс
- Productivity — продуктивность скважин
- GDI — гидродинамическая интерпретация
- Temperature — устьевая температура и давление
- Components — изменение состава газа
- Base — сводный расчёт фонда и добычи

`code_MBAL/` — библиотека расчётных функций.

`runner.py` — последовательный запуск полного расчёта.

## Установка и запуск

```powershell
py -3.10 -m pip install -r requirements.txt
py -3.10 runner.py
```

Запуск отдельного модуля выполняется из корня проекта, например:

```powershell
py -3.10 code_sheets/PVT/pvt_controller.py
```

При сборке в `.exe` изменённые пользователем файлы в `run_data` сохраняются и
не перезаписываются исходными данными при следующем запуске.

## Результаты и ограничения

«База» строит условный прогноз на 1200 месяцев (100 лет). По умолчанию
применяются ограничения исходной книги: максимальная депрессия 10 МПа,
минимальная скорость на забое 1,5 м/с, максимальная скорость на устье 26 м/с
и минимальное устьевое давление 5 МПа. Причина остановки записывается в
`operation_limit`. Автоматический повторный запуск после остановки выключен;
при необходимости его можно включить параметром `restart_stopped_wells`.

Контроллеры сохраняют расчётные JSON-файлы и PNG-графики в своих папках.

## Тесты

```powershell
py -3.10 -m unittest discover -s tests -v
```

Для совместимости модуль P/Z записывает результат как в `pz_output.json`,
так и в прежний файл `pz_outputs.json`.
